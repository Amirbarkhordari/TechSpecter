## Getting Help

1. Read the documentation linked above
2. Run diagnostics: `techspecter doctor`
3. Search [existing issues](https://github.com/Amirbarkhordari/TechSpecter/issues)
4. Open a [GitHub Discussion](https://github.com/Amirbarkhordari/TechSpecter/discussions) for questions
5. Open a [bug report](https://github.com/Amirbarkhordari/TechSpecter/issues/new) with reproduction steps

## Bug Reports

Include:

- TechSpecter version (`techspecter --version`)
- Python version and OS (`techspecter doctor --json`)
- Command executed and configuration used
- Expected vs. actual behavior
- Relevant logs (use `--debug` for verbose output)

## Security Issues

Do **not** open public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md).

## Commercial Support

TechSpecter is an open-source community project. Commercial support is not currently offered by the core maintainers.
